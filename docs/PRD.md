# 한국 주식 조건 신호 앱 PRD

상태: MVP 기준선  
기준일: 2026-08-15  
가칭: 시그널랩. 이름·아이콘·강조색은 중앙 설정으로 교체한다.

## 1. 제품 목적

한국 주식 일봉 데이터를 사용해 사용자가 만든 조건을 평가한다. 결과는 `사용자 설정 조건 충족 신호`로 부른다. 투자 추천, 자동 실주문, 수익 보장을 하지 않는다.

핵심 가치:

- 초보 사용자도 최대 5개 지표로 전략 생성
- 완성 일봉 기준 매수·매도 조건 추적
- 실제 매매 체결 직접 기록
- 과거 데이터 누수 없는 조합 성과 비교
- 공개 사용자의 작성 매매 기록 기반 수익률 비교

## 2. 사용자

- 초보 탐색자: 기본 지표값과 짧은 설명 필요
- 전략 실험자: 조건 그룹, 지표값, 종목 범위 수정 필요
- 수동 투자자: 앱 밖 체결 등록, 부분매도, 매도 규칙 감시 필요
- 랭킹 참가자: 잠긴 규칙, 공통 체결 모델, 투명한 성과 원장 필요

## 4. 핵심 정책

### 종목 범위

전략 버전은 한 `UniverseVersion`을 고정한다. KOSPI 200, KOSDAQ 150, KOSPI 전체, KOSDAQ 전체, 통합, 사용자 지정 목록을 지원한다. 구성 종목 이력은 효력일 기준이다. 현재 목록을 과거에 소급하지 않는다. 범위에서 빠진 종목도 열린 포지션 매도 감시는 계속한다.

### 신호

- 완성 일봉만 평가
- `false → true` 전환만 새 신호 저장
- 전략 버전·종목·주기·봉·종류 유일
- 누락·지연 데이터면 평가 중단
- 계산값, 규칙 근거, 데이터 버전 저장
- 매수 신호만으로 수동·자유 연습 포지션 생성 금지

### 실제 매매 기록

사용자는 앱 밖에서 체결된 매수·매도 가격, 수량, 일시를 `MANUAL_LIVE` 원장에 직접 기록한다. 추가매수와 부분매도를 허용한다. 체결 ledger가 원본이고 포지션은 재생 가능한 캐시다. 숫자는 DB `numeric`과 코드 Decimal을 쓴다. 앱은 실제 주문이나 모의 체결을 실행하지 않는다.

### 매도

첫 BUY 후 포지션을 연다. 열린 포지션만 평가한다. 보호 규칙은 서로 OR다. 기술 조건 내부만 `ANY` 또는 `ALL`이다. 기술 조건은 최대 3개다. 고정 손절, 목표수익, 추적 손절, 최대 보유 거래일, 수동 관리를 지원한다.

같은 봉의 여러 원인은 신호 하나에 병합한다. 조건이 계속 참이면 재발송하지 않는다. 거짓 뒤 다시 참이면 새 신호를 만든다. 전량 청산 즉시 활성 신호와 미발송 알림을 취소한다.

### 사용자 랭킹

- 공개 프로필만 포함
- 테스트 기간에는 실제 매매 체결 기록 1회 이상
- 수익률: 매도 실현손익 합계 ÷ 해당 매도 수량의 매입원가 합계. 매도 전에는 0%
- 순위: 수익률 내림차순
- 동률: 매도 횟수, 긴 기록 기간, 닉네임
- 증권사 인증 내역이 아닌 사용자 작성 기록임을 항상 고지
- 개별 체결, 실제 투자금, 이메일과 미청산 포지션은 공개하지 않음
- 공개 프로필에는 사용자가 공개한 전략의 최신 버전, 지표 조합, 조건 관계, 종목 범위를 표시하고 복사를 허용
- 공개 전략은 랭킹 수익률에 실제 사용된 전략과 다를 수 있음을 고지

## 5. 사용자 흐름

1. 위험 고지 확인, 로그인 또는 체험
2. 종목 범위 선택
3. 최대 5개 지표와 AND/OR 그룹으로 전략 생성
4. 일봉 확정 뒤 신호 수신
5. 실제 체결 내역 직접 등록
6. 체결 뒤 포지션과 매도 규칙 연결
7. 부분매도 뒤 잔여 수량 감시, 전량매도 뒤 종료
8. 공개 동의 후 실제 매매 기록 수익률 랭킹 참여
9. 공개 동의 뒤 프로필과 성과 공개
10. 공개 사용자 신고·차단. 차단한 프로필은 공개 view에서 제외

## 6. 화면

하단 메뉴는 `홈 / 랭킹 / 만들기 / 알림 / MY`다. 필수 화면은 온보딩, 인증, 대시보드, 범위·검색·관심 종목, 전략 CRUD, 지표 설명, 신호 상세, 실제 체결 등록, 포지션 목록·상세, 추가매수, 부분·전량매도, 매도 규칙, 손익·종료 기록, 사용자 랭킹, 공개 프로필, 알림 설정, 공급자 상태, 개인정보·공개 설정, 계정 삭제다.

모든 주요 화면은 로딩, 빈 값, 오류, 오프라인, 지연 데이터, 권한 거부 상태를 가진다. 상승·하락은 색과 부호·화살표를 함께 쓴다.

## 7. 비기능 요구

- Asia/Seoul 거래 달력. DB 시각은 `timestamptz`
- strict TypeScript와 공유 입력 schema
- 사용자 데이터 RLS, 서버 권한 재검사
- 서비스 키와 공급자 키는 서버 전용
- 신호와 outbox 한 DB transaction
- 원장 append-only와 정정 이벤트
- 로그 비밀값 마스킹
- 동일 seed 재현
- 접근성: 색 외 표기, 큰 글자, 스크린리더 이름, 충분한 터치 영역

## 8. 완료 기준

- 성공 기준 15개 흐름이 Mock 데이터로 연결됨
- 필수 테스트가 자동화됨
- DDL이 모든 최소 테이블, RLS, 공개 view, 원장 보호, 활성 트랙 유일 조건을 포함함
- 외부 키 없이 로컬 실행 가능
- 실제 공급자·푸시는 연결 성공으로 표기하지 않음
- 법무·데이터 계약의 미확정 항목을 출시 차단 조건으로 추적

## 10. 고지 문구

`본 앱의 신호, 랭킹, 백테스트는 정보·교육 목적입니다. 투자자문 또는 수익 보장이 아닙니다. 사용자 랭킹은 증권사가 인증하지 않은 직접 작성 매매 기록을 기반으로 하며, 과거 수익률은 미래 성과를 보장하지 않습니다.`
