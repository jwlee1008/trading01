# 한국 주식 조건 신호 앱 PRD

상태: MVP 기준선  
기준일: 2026-08-15  
가칭: 시그널랩. 이름·아이콘·강조색은 중앙 설정으로 교체한다.

## 1. 제품 목적

한국 주식 일봉 데이터를 사용해 사용자가 만든 조건을 평가한다. 결과는 `사용자 설정 조건 충족 신호`로 부른다. 투자 추천, 자동 실주문, 수익 보장을 하지 않는다.

핵심 가치:

- 초보 사용자도 최대 5개 지표로 전략 생성
- 완성 일봉 기준 매수·매도 조건 추적
- 실제 수동 보유, 자유 연습, 공식 랭킹 원장 완전 분리
- 과거 데이터 누수 없는 조합 성과 비교
- 비용 포함 공식 페이퍼 성과 공개

## 2. 사용자

- 초보 탐색자: 기본 지표값과 짧은 설명 필요
- 전략 실험자: 조건 그룹, 지표값, 종목 범위 수정 필요
- 수동 투자자: 앱 밖 체결 등록, 부분매도, 매도 규칙 감시 필요
- 랭킹 참가자: 잠긴 규칙, 공통 체결 모델, 투명한 성과 원장 필요

## 4. 핵심 정책

### 종목 범위

전략 버전은 한 `UniverseVersion`을 고정한다. KOSPI 200, KOSDAQ 150, KOSPI 전체, KOSDAQ 전체, 통합, 사용자 지정 목록을 지원한다. 구성 종목 이력은 효력일 기준이다. 현재 목록을 과거에 소급하지 않는다. 범위에서 빠진 종목도 열린 포지션 매도 감시는 계속한다.

### 신호

- 완성 일봉만 평가
- `false → true` 전환만 새 신호 저장
- 전략 버전·종목·주기·봉·종류 유일
- 누락·지연 데이터면 평가 중단
- 계산값, 규칙 근거, 데이터 버전 저장
- 매수 신호만으로 수동·자유 연습 포지션 생성 금지

### 세 원장

| 종류 | 진입 | 추가매수·부분매도 | 공식 랭킹 |
|---|---|---:|---:|
| `MANUAL_LIVE` | 사용자 실제 체결 등록 | 허용 | 제외 |
| `SANDBOX_PAPER` | 사용자 주문 확인 후 다음 가능 세션 시가 | 허용 | 제외 |
| `RANKED_PAPER` | 잠긴 전략 신호 뒤 서버 자동 가상 주문 | 금지 | 포함 |

체결 ledger가 원본이다. 포지션과 NAV는 재생 가능한 캐시다. 숫자는 DB `numeric`과 코드 Decimal을 쓴다.

### 페이퍼 체결

- 정수 수량
- 당시 거래 가능한 비수정 공식 시가
- 방향별 불리한 slippage와 유효 호가 반올림
- 버전 고정 수수료·세금·spread·fill 모델
- 거래정지, 시가 없음, 0거래량, 지연·불확실 데이터는 미체결
- 전량 체결 또는 전량 미체결
- 현금 부족 BUY와 보유량 초과 SELL 전량 거부
- idempotency key 필수

랭킹 BUY는 다음 세션 한 번만 시도한다. 실패 시 만료한다. 랭킹 SELL 실패는 `EXIT_PENDING`으로 두고 다음 가능 세션마다 재시도한다.

### 매도

첫 BUY 후 포지션을 연다. 열린 포지션만 평가한다. 보호 규칙은 서로 OR다. 기술 조건 내부만 `ANY` 또는 `ALL`이다. 기술 조건은 최대 3개다. 고정 손절, 목표수익, 추적 손절, 최대 보유 거래일, 수동 관리를 지원한다.

같은 봉의 여러 원인은 신호 하나에 병합한다. 조건이 계속 참이면 재발송하지 않는다. 거짓 뒤 다시 참이면 새 신호를 만든다. 전량 청산 즉시 활성 신호와 미발송 알림을 취소한다.

### 공식 랭킹

- 사용자당 활성 트랙 1개
- StrategyVersion, UniverseVersion, SellRuleVersion, fill/cost 모델, 초기 자본 잠금
- 초기 자본 10,000,000원
- 입출금·레버리지·공매도·소수점 금지
- 종목당 주문 전 NAV 10%, 최대 10종목, 종목당 열린 포지션 1개
- 추가매수, 주문 건너뛰기, 취소, 가격 선택 금지
- 순위: 같은 기간 비용 차감 누적수익률 내림차순
- 동률: 낮은 MDD, 긴 운용 기간, 닉네임
- 범위 필터는 행만 거르고 통합 순위는 재계산하지 않음
- 재시작 cooldown 기본 30일. 옛 트랙과 손실 보존

동일 세션 후보 초과 시 `signal_strength` 내림차순, 과거 정보만 쓴 유동성 내림차순, 종목 코드 오름차순으로 고정한다.

## 6. 화면

하단 메뉴는 `홈 / 랭킹 / 만들기 / 알림 / MY`다. 필수 화면은 온보딩, 인증, 대시보드, 범위·검색·관심 종목, 전략 CRUD, 지표 설명, 신호 상세, 실제 체결 등록, 페이퍼 주문, 포지션 목록·상세, 추가매수, 부분·전량매도, 매도 규칙, 손익·종료 기록, 조합·지표·사용자 랭킹, 공개 프로필, 알림 설정, 공급자 상태, 개인정보·공개 설정, 계정 삭제다.

모든 주요 화면은 로딩, 빈 값, 오류, 오프라인, 지연 데이터, 권한 거부 상태를 가진다. 상승·하락은 색과 부호·화살표를 함께 쓴다.

## 7. 비기능 요구

- Asia/Seoul 거래 달력. DB 시각은 `timestamptz`
- strict TypeScript와 공유 입력 schema
- 사용자 데이터 RLS, 서버 권한 재검사
- 서비스 키와 공급자 키는 서버 전용
- 신호와 outbox 한 DB transaction
- 원장 append-only와 정정 이벤트
- 로그 비밀값 마스킹
- 동일 seed 재현
- 자동 후보는 최대 4개. benchmark 통과 뒤만 5개 flag 활성
- 접근성: 색 외 표기, 큰 글자, 스크린리더 이름, 충분한 터치 영역

## 8. 지표·조합 평가

조합 성과는 t일 종가 신호, t+1 가능 세션 시가 진입, 5·20·60거래일 비용 후 초과수익을 쓴다. 평가 중복 신호와 미완료 표본은 뺀다. 훈련·검증·홀드아웃, rolling walk-forward, point-in-time 종목 구성과 데이터를 쓴다. 신호 30개 미만은 `데이터 부족`이다.

지표 티어 점수는 제거 시 점수 하락 50%, 기간·종목 안정성 30%, 중복 제거 출현 20%다. UI에 `과거 데이터상 견고성 등급이며 미래 수익 예측이 아님`을 표시한다.

## 9. 완료 기준

- 성공 기준 15개 흐름이 Mock 데이터로 연결됨
- 필수 테스트가 자동화됨
- DDL이 모든 최소 테이블, RLS, 공개 view, 원장 보호, 활성 트랙 유일 조건을 포함함
- 외부 키 없이 로컬 실행 가능
- 실제 공급자·푸시는 연결 성공으로 표기하지 않음
- 법무·데이터 계약의 미확정 항목을 출시 차단 조건으로 추적

## 10. 고지 문구

`본 앱의 신호, 랭킹, 백테스트는 정보·교육 목적의 기계적 산출물입니다. 투자자문 또는 수익 보장이 아닙니다. 백테스트와 페이퍼 성과는 미래 성과를 보장하지 않습니다. 비용, 데이터 지연, 시장 상황으로 실제 결과가 달라질 수 있습니다.`
